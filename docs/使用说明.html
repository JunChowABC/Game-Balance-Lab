01

安装与启动

首次使用建议在 Windows + Chrome / Edge 桌面浏览器中操作。
将 V1.5 工程包解压到独立文件夹

例如 D:\GameBalanceLab\。解压后根目录有 启动工作台.bat，子目录 dist 内有 index.html 等网页文件。

推荐：双击「启动工作台.bat」

电脑已安装 Python、8000 端口未占用时，脚本会启动本地网页服务并尝试打开浏览器。命令窗口需要保持运行。

如果 BAT 启动失败，手动启动

进入 dist 文件夹，在 Windows 资源管理器的地址栏输入 cmd 并回车，再执行下面命令：

py -m http.server 8000
在浏览器打开工作台

地址输入 http://localhost:8000/。这是本机地址，和公网网站不同。

http://localhost:8000/
避开你之前遇到过的 404：如果命令窗口已经位于 ...\dist>，不要再次添加 --directory dist。否则 Python 会错误地寻找 dist\dist。
02

先认识唯一的工作界面

V1.5 只需通过一个工作台完成导入、映射、调参和结果查看，不必在多个页面来回切换。
左侧：你的项目列表（一个 Excel 可形成一个本地项目，点击切换）。
主界面左栏：选择来源 Sheet / 数值列 / 行范围，并定义推演参数。
主界面右栏：指标卡、曲线、异常提示、明细表和数据导出。
底部折叠区域：原始 Excel 的单元格与公式查看，通常不需要展开。
03

导入你自己的游戏项目 Excel

这里的“新建项目”就是导入一个原始工作簿；V1.5 不需要先手动创建空白项目。
点击「＋ 导入项目 Excel」

也可以点击顶部或首页中间的导入按钮。弹出系统文件选择窗口。

选择自己的 .xlsx 或 .xlsm 文件

例如 示例角色成长.xlsx 或 示例敌人属性.xlsx。XLSM 内的 VBA 宏不会运行。

等待加载完成，再在左侧项目列表点击项目

系统会以文件名生成本地项目，读取 Sheet 列表；大文件首次解析可能较慢，避免连续重复点击导入。

重要：工具按本地浏览器方式读取工作簿，不上传服务器，也不修改磁盘上的原始 Excel。数值项目会保存在当前浏览器的本地 IndexedDB 中。
目前支持的类型：.xlsx、.xlsm。旧格式 .xls、.csv 不是 V1.5 这个“原生工作簿入口”的受支持格式，先用 Excel 另存为 XLSX 后再导入。
04

选中你真正想推演的数值

决定图表 X 轴是什么、Y 轴是什么，是推演正确的关键。
控件应该填什么例子常见错误
工作表 Sheet承载目标数值的原始 Excel 工作表角色成长选到了只有说明文字的 Sheet
横轴列按行变化的等级、天数或阶段A（等级）使用了角色名称等文本列
数值列要观察的数值指标D（攻击力）选到了公式说明文字或空列
起始 / 结束行包含有效数值的 Excel 行号4 – 110把表头行也当作数据行
自动识别推荐列根据数值连续性尝试自动选择点击后检查结果把自动推荐当成完全正确
列号≠字段名：如果「攻击力」在 D 列，输入 D，不是输入“攻击力”。按钮下方的字段推荐只是快捷切换。数据范围里至少需要 2 组成对的数值，横纵轴都必须能被识别为数字。
05

配置推演规则，并直接观察调整效果

用 Excel 已保存的值作为 A 方案，使用自定义规则生成 B 方案。

建议第一次只做一件事：整体倍率 +20%

推演规则选「整体数值倍率」

只调整比例，不同时修改其他参数，便于观察影响。

「整体倍率 k」设置为 1.2

表示每行的原数值都乘以 1.2，即提高 20%。

查看右侧结果

在图表中确认紫色推演曲线高于灰色原始曲线，再检查逐行结果。

需要重新开始时点击「恢复基准」

将推演参数重置为默认值；原始 Excel 文件不会被改动。

四种基础规则怎么选择？

推演规则计算思路适合的策划问题
整体数值倍率y × k（结果至少为 0）整体提高敌人攻击、经验收益或战力曲线
逐级固定增量y + t × b每提升 1 级再额外增加一定数值
复合成长率y × (1 + g/100)^t测试中后期指数成长是否过快
综合调整(y×k+t×b)×(1+g/100)^t联合调整倍率、线性增量和增长率

其中 y 是原始纵轴数值，t 是当前横轴减第一项横轴，k 为倍率，b 为每单位增量，g 为百分比增长率。快捷规则的结果会被限制为不小于 0。

06

如何读懂可视化结果

先看末项差异，再看整个成长节奏，最后核查异常点和逐行数值。
结果解释怎么判断
有效数据点实际参与计算的行数若明显少于预期，检查是否有空值、文本或公式缓存缺失
原始末项数值所选行范围内最后一个有效数据点的原值先对照 Excel 确认选列正确
推演末项数值最后一个有效点的方案 B 结果确认推演方向与预期一致
末项变化方案 B 末项减去原始末项只说明末项，不代表整条曲线都合理
异常提示相邻回退、持平或大幅跃升等简单规则提示用于定位候选问题，不能单独当成平衡性结论
逐级数值差异Excel 行、横轴、原值、推演值、绝对和百分比差异精确确认某一等级的参数影响
07

需要核对公式时：展开原始工作表预览

这一区域是辅助工具，不是必须操作的主流程。
展开最下方「原始 Excel 数据预览」

只在需要确认某个数值从何而来时使用。

设置「起始行」「起始列」并点击跳转

例如填 10 和 D，跳转到 D10 附近。

点击单元格

查看 Excel 保存的单元格缓存值，以及该单元格是否带有原始公式。

注意：看到 Excel 公式不代表工具能够重新计算那条公式。V1.5 保留原公式文本供核对，但推演引擎计算的是“你选定的数列 + 你配置的新规则”。

10

高级：自定义公式推演

熟悉基础规则后，可以用表达式建立同一行其他属性对当前指标的影响。

在「推演规则」中选择 自定义表达式（高级），左侧会出现表达式输入框。常用变量如下：

变量含义例子
y当前行所选数值列的 Excel 原值攻击力 / 攻击力
x当前行横轴列的数值当前等级
t当前行横轴减去首个有效点的横轴等级 20 相对首点等级 1：t=19
k倍率控件的值1.2
b逐单位固定增量的值50
g百分比复合增长参数3 表示 3%
A / C 等当前 Excel 同一行其他数值列（大小写不敏感）C 列数值参与当前行计算

表达式示例

max(0, y * 1.2)

当前选定数值列整体放大 20%。

max(0, y + t * 50)

在每一级额外添加 50 点数值。注意 t 根据横轴差值，而不是单纯根据行号。

max(0, y * k + C * 0.15)

除了原值倍率，还加入同一行 C 列数值的 15%。C 列必须存在可计算的数值缓存。

高级表达式支持 + - * / ^、min、max、abs、round、floor、ceil、pow、sqrt、log、exp、clamp。不支持 Excel 的任意函数和跨 Sheet 公式，不支持 VLOOKUP、INDIRECT 或 VBA。
11

常见问题与能力边界

排查时优先对照控件、数据范围和浏览器环境。
① 浏览器显示 404 或页面空白
检查命令窗口当前目录是否是 dist，目录中应有 index.html。在 dist 中运行 py -m http.server 8000，不要附加第二个 --directory dist。如果 8000 端口被旧版本占用，先到旧命令窗口按 Ctrl+C 停止服务。
② 导入成功，但图表提示“缺少成对数值”
横纵轴都需要是数值列，并在同一行存在有效数值；检查是否把表头行、空白行、文本字段或隐藏计算列选入范围。先在原始预览中找到表头和第一条有效行，再填写准确行列。
③ 为什么某些 Excel 公式行没有数值？
浏览器不会对 Excel 的原公式进行完整计算。若工作簿没有保存对应的公式缓存结果，那些行可能没有可用数值。请在桌面 Excel 中打开原表，完成重新计算并保存后再导入。
④ 为什么修改倍率后，关联属性或战斗结果没有变？
V1.5 只对当前选择的数值序列应用假设公式，并不连带重算整个工作簿中的依赖关系。它适合评估成长趋势变化，不是完整的角色属性、战斗伤害、资源经济依赖引擎。
⑤ 我的 XLSM 宏文件安全吗？
当前工具只按只读方式解析 XLSM 内容，不执行 VBA，也不连接外部数据源。但仍建议在受控电脑中使用自己的商业数值文件，不要把包含项目原表的文件提交到公开仓库。
⑥ 文件非常大，导入慢或提示限制怎么办？
目前单文件上限约 40 MB，单张 Sheet 解压 XML 上限约 32 MB，每个 Sheet 最多加载前 22 万个有效单元格。单次映射的行跨度最多 15,000 行，曲线单次最多提取约 700 个点。非常大的项目建议先明确需要分析的 Sheet，按系统拆成可控工作簿副本。
⑦ 为什么之前的项目不见了？
项目和文件缓存在当前浏览器的 IndexedDB 内。更换浏览器、清理站点数据，或者换成不同的端口（例如 8000→8001）时，可能显示为另一个独立的存储空间。原始 Excel 文件不受影响，重新导入即可。
⑧ 能不能一次比较两个 Excel 版本或模拟玩家 30 天行为？
V1.5 当前主要是“同一原始 Excel 数据 + 自定义公式”的 A/B 假设推演。它没有把完整 Excel A/B 重算、跨 Sheet 联动、自动模拟玩家行为等功能统一进当前工作台。若要实现，需要后续明确公式依赖和行为仿真模型。
