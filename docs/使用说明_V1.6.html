01 / PRODUCT OVERVIEW

认识工具与完整工作流程

这是一款用于显式数值依赖推演的本地工作台。你负责指定真实的输入数据和公式规则，工具负责计算“某个参数改变后，关联属性与经济指标如何变化”。

建立项目→导入 Excel→绑定输入参数→配置公式依赖→修改方案 B→分析并导出
① 输入来源

演示数值、人工录入的基准值、Excel 固定单元格或按等级排列的数值列。

② 计算能力

数学表达式、同级属性依赖、上一级累计指标、受影响节点重算。

③ 输出内容

A/B 指标卡、成长曲线、依赖链、逐级差异、CSV 与模型 JSON。

使用前必须知道：导入 Excel 并不等于自动执行整本工作簿的所有原生公式。只有配置在本工具里的公式节点，才会参与依赖重算。
02 / GET STARTED

下载安装和启动程序

方式 A：Windows 一键启动（推荐）

  1. 从 GitHub 下载 V1.6 源码或获取 V1.6 工程 ZIP，完整解压，不要直接在压缩包内运行。
  2. 确认目录含有 启动工作台.bat 和 dist 文件夹。
  3. 双击 启动工作台.bat，脚本会尝试启动本地 HTTP 服务并打开浏览器。
  4. 在浏览器访问 http://localhost:8000/，看到欢迎页即成功。关闭服务器窗口或按 Ctrl + C 停止服务。

方式 B：命令行手动启动

在 dist 文件夹空白处打开命令窗口，执行：

py -m http.server 8000

如果你的命令行在工程根目录（不在 dist 内），才执行：

py -m http.server 8000 --directory dist
你之前遇到过 404：当命令行已经在 ...\dist> 时，又加 --directory dist 会指向不存在的 dist\dist，因此出现 File not found。

首次打开会看到什么？

初次没有项目时，欢迎页提供「导入我的 Excel」和「先体验虚构 RPG 示例」两种入口。当前 V1.6 没有独立的“完全空白项目”创建按钮。

04 / PROJECTS

创建、切换、重命名和删除项目

A · 用演示数据建项目

点击「＋ 创建演示模型」或欢迎页的「先体验虚构 RPG 示例」。系统新增一份虚构 RPG 项目，不需要 Excel。

B · 用真实 Excel 建项目

点击「＋ 导入项目 Excel」或「导入 Excel」，选择 .xlsx/.xlsm。成功读取后即创建一个新项目。

日常项目操作

  1. 切换：左侧「我的项目」点击项目名称，工作台读取对应的模型和 Excel。
  2. 更改名称：在当前项目右上角点击「重命名」，输入新名称。
  3. 改变推演长度：调整「模拟等级」，允许 1–500 的整数，默认为 30 级。
  4. 移除：点击「移除项目」，确认后删除当前浏览器中保存的项目及其工作簿缓存，不删除电脑上的 Excel 原文件。
不支持原地替换来源 Excel：当前界面顶部的「导入 Excel」会创建一个新的项目，并不会把当前项目底层工作簿更新为新文件。需要换文件版本时，请另导入为新项目，再检查节点和映射。
05 / FIRST RUN

从零完成第一次联动模拟（教学案例）

先用内置虚构模型走通一次，确保理解“输入 → 下游公式 → 经济结果”的变化，再导入自己的大规模数值表。

  1. 打开欢迎页，点击 先体验虚构 RPG 示例，或点击左栏「＋ 创建演示模型」。
  2. 确认顶部「模拟等级」为 30。
  3. 在左侧「① 输入参数」找到 基础攻击（baseattack）。
  4. 保留基准值 100、倍率 1，在「增量」中输入 100，随后按 Tab 或点击别处。
  5. 查看右侧「关键指标」、将「显示指标」依次切换为「最终攻击」「综合战力」「累计金币盈余」。
  6. 在「参数影响链」中选基础攻击，观察最终攻击、战力、升级成本和金币产出的关联路径。
  7. 向下滚动至「数值差异明细」，查看各级 A/B 的变化；最后点击顶部「导出数值 CSV」。
预期结果：在虚构示例中，Lv.30 最终攻击从 488 变为 588；综合战力从 1,670 变为 1,870。你会同时看到金币和养成成本的下游变化。请以实际运行界面显示的值为准。

示例关系可以理解为：

基础攻击 +100→最终攻击→综合战力→金币产出→累计金币盈余
最终攻击→升级成本→累计养成成本

07 / DATA BINDING

绑定 Excel：固定单元格和逐级数值列

绑定工作属于「③ Excel 数据绑定」区域。导入 Excel 后，这个区域会显示下拉框、地址输入和应用按钮。

操作示意 · 导入 Excel 后的绑定表单（示例字段）
应用绑定取消绑定

原工作簿“角色成长”第 2 行到第 31 行的 B 列数值，将依次作为等级 1–30 的基础攻击。

方式一：固定单元格

  1. 在「绑定节点」选一个输入参数，例如 powerattackweight。
  2. 选择参数所在 Sheet，例如「经济参数」。
  3. 绑定方式选「固定单元格」，地址输入 B3。
  4. 核对预览显示的是有效数字，然后点击「应用绑定」。

例如绑定 经济参数!B3，那么模拟的每一级都会使用这一固定的数字作为基准值。

方式二：按级读取列

  1. 在「绑定节点」选 baseattack。
  2. 工作表选择「角色成长」，绑定方式选「按级读取列」。
  3. 「地址 / 列」填写 B，「起始行」填写 2。
  4. 预览会显示前 5 级取到的数字；确认后点击「应用绑定」。
  5. 模拟时第 1 级使用 B2，第 2 级使用 B3，第 30 级使用 B31。
使用输入参数表里的「数据源」按钮，可以快速定位到相应节点的绑定设置。也可在绑定区点击「扫描当前 Sheet 的可映射数值候选」快速寻找“有标签的数值单元格”；该扫描仅提供候选，不会自动建立整套公式依赖。
如果某一级映射的单元格是空白、文本、错误值或没有缓存结果的公式，系统会中断本轮计算并提示具体节点与地址。请修复源文件或调整绑定后再运行。
08 / PARAMETERS & SCENARIOS

输入参数：基准值、倍率、增量如何使用？

字段说明影响
基准值未绑定 Excel 时输入 A 方案使用的默认值改变基础假设，A/B 都可能重新计算
倍率方案 B 对当前输入值的乘数；默认 1只影响 B 的该输入和下游节点
增量方案 B 在乘倍率后额外增加的数值；默认 0只影响 B 的该输入和下游节点
数据源无绑定则显示「示例/手动」，有绑定显示 Sheet 与地址有 Excel 绑定时以 Excel 数字为 A 基准

计算约定：

A输入 = Excel读取值（已绑定）或手动基准值
B输入 = A输入 × 倍率 + 增量
基础攻击 +100

倍率填 1，增量填 100。若 A=200，则 B=300。

经验需求 +20%

倍率填 1.2，增量填 0。若 A=1,000，则 B=1,200。

成本 -10%

倍率填 0.9，增量填 0。若 A=500，则 B=450。

新建输入参数

  1. 点击「① 输入参数」右上的「＋ 参数」。
  2. 输入唯一节点 ID，例如 weaponbonus（英文字母开头，小写数字/下划线）。
  3. 输入中文名称，例如「武器加成」。
  4. 修改基准值、倍率、增量，并在公式中引用它；否则不会影响任何计算结果。
当前界面允许新增输入参数，但没有独立的输入节点删除按钮；需要删除大量配置时建议重新组织模型。内置 level 为等级序号输入，不支持在界面编辑其倍率或增量。
09 / FORMULA ENGINE

建立属性、战力、经济和跨级累计公式

这一部分是 V1.6 的数值计算核心。公式需要使用节点 ID，而不是直接输入「基础攻击」这样的中文名称。

9.1 内置教学公式示例

attack = baseattack + (level-1)*attackgrowth + weaponattack

defense = basedefense + (level-1)*defensegrowth

hp = basehp + (level-1)*hpgrowth

power = round(attack*powerattackweight
            + defense*powerdefenseweight
            + hp*powerhpweight)

upgradecost = round(costbase*pow(costgrowth,level-1)
                    + attack*attacktraincost)

goldincome = round(stagegold + power*goldperpower)

goldbalance = prev_goldbalance + goldincome - upgradecost

totalcost = prev_totalcost + upgradecost
上面的 attack = 只是用于说明“节点 ID 与公式”的对应关系。软件已有公式节点时，直接在这个节点的公式输入框填写等号右侧的表达式，例如 baseattack + (level-1)*attackgrowth + weaponattack。

9.2 编辑、新建、删除公式

  1. 在「② 计算公式」找到想编辑的节点，输入新的数学表达式。
  2. 按 Tab 或点击别处应用修改。模型会检查变量和依赖，再重新推演。
  3. 需要新公式，点击「＋ 公式」，输入英文节点 ID 与中文名称；然后编辑默认表达式。
  4. 需要删除公式节点，点击该公式旁的「删除」。如果别的公式引用了它，必须先调整引用关系，否则会提示未知节点。

9.3 同级依赖与跨级依赖

同级依赖

power 引用 attack、defense、hp，会在同一等级先计算属性，再计算战力。

跨级依赖

prev_goldbalance 代表上一级余额。第一级的 prev_ 值默认为 0，可累加金币盈余。

错误校验：如果公式变量不存在、同级出现循环依赖、除以零，或产生无效数值，页面会在右侧显示「无法计算」。需先修正错误才会恢复图表。
10 / RESULT READING

如何阅读可视化推演结果？

10.1 关键指标卡

右侧指标卡通常显示 B 方案末级数值、A 基准数值和变化差异。若 A 为 0，系统会提示无法以正常百分比表达。

10.2 A/B 成长曲线

  1. 在「显示指标」下拉框选择要分析的公式节点，比如「综合战力」或「累计金币盈余」。
  2. 灰色线代表 A 基准，紫色线代表 B 调整后。
  3. 鼠标在图表上移动，读取当前等级的 A、B 和差异。
  4. 关注曲线是否偏离目标成长节奏，以及是否出现异常放大或收益无法覆盖成本等现象。

10.3 参数影响链

  1. 在「追踪参数」下拉框选择基础攻击、成本系数等输入节点。
  2. 工具列出引用关系和跨级关系，并显示末级变化。
  3. 如果没有下游节点，说明当前参数还未被其他公式引用。

10.4 数值差异明细

表格按等级展示多个指标的 A / B 数值，常见指标包括最终攻击、综合战力、养成成本、金币产出、金币盈余。长模型可能为界面性能抽样显示部分等级，但导出的 CSV 会包含完整的逐级数据。

10.5 辨别计算结果的意义

观察结果策划应如何判断
战力升高、金币盈余变差检查养成成本增幅是否高于战力带来的收益增幅
修改某属性，战力不变先确认战力公式是否实际引用该属性
累计成本连续上升确认成本上升是否符合目标节奏，结合获取与消耗平衡判断
前期曲线非常平稳、后期突变核对幂函数、倍率、解锁节点等是否符合预期
11 / REAL PROJECT WORKFLOW

把真实项目 Excel 转成可用的依赖模型

不建议第一天就把大型 MMO 数值表的所有 Sheet 全部建模。应该先选一条实际研发需要分析的闭环。

基础属性→属性成长/装备→战力/伤害→通关收益→升级消耗→资源盈余

一个可操作的“自己的项目”配置案例

  1. 选目标：例如判断“提高基础攻击是否让升级资源不足”。
  2. 定观察范围：先选 30 级，确认对应数据完整，再扩大到 60 或 100 级。
  3. 导入 Excel：选择有属性数值的原始工作簿，系统自动创建项目。
  4. 校对输入：将 baseattack 绑定属性列；将攻击成长系数或训练成本系数绑定实际 Sheet 的单元格。
  5. 校对公式：对照原项目的属性、战力、升级成本和收益公式，逐个替换示例表达式。缺少的中间变量用「＋ 参数」「＋ 公式」补充。
  6. 先做 A 校验：令倍率=1、增量=0，确认输出的 A 曲线与原项目 Excel/配置表一致；如果不一致，不应继续拿 B 做决策。
  7. 做 B 试验：把某参数改为 +10%、+100 或 -20%，观察全链路差异；每次只改变一个主要参数便于解释。
  8. 导出报告：输出 CSV 和模型 JSON，记录假设和最终决定。
最重要的验收点：基准 A 必须与真实项目经过校准的数值一致，才能相信联动结果。仅仅因为 Excel 成功导入、图表能显示，不代表模型已经正确还原真实游戏。

放置养成离线收益系数 → 每日产出 → 强化花费 → 下一阶段成长资源盈余、成长成本
休闲关卡关卡参数 → 消耗 / 奖励 → 道具库存 / 体力需求经济消耗、关卡奖励节奏

当前模型使用的是“逐等级”序列。若你的游戏分析的是逐日或逐关卡，可暂时把 level 作为序列索引使用，但要清楚标明语义；这不是自动支持所有游戏机制的专用计算器。

项目保存在哪里？

项目保存在当前浏览器的 IndexedDB，包含你导入的工作簿副本与模型数据。关闭网页后通常可以恢复；但换浏览器、切换本地站点端口、清空站点数据或用无痕模式，可能看不到之前的项目。

13 / TROUBLESHOOTING

常见问题与解决方法

① 浏览器显示 404 / File not found

检查命令窗口所在目录。如果已经是 ...\dist>，启动命令应为 py -m http.server 8000；不要重复加 --directory dist。

② 端口 8000 被其他项目占用了

停止占用 8000 的服务器，或在 V1.6 的 dist 文件夹执行 py -m http.server 8765，然后打开 http://localhost:8765/。不同端口是不同浏览器数据源，旧 IndexedDB 项目不会自动同步。

③ 双击 bat 后提示找不到 py

说明 Python Launcher 不可用。先在命令行运行 py --version 检查；可安装 Python，或使用其他本地静态 HTTP 服务器启动 dist。

④ Excel 导入失败 / 超过限制

确认格式是 .xlsx/.xlsm，未损坏且小于 40MB。若某个 Sheet 的 XML 解压后过大，可以先把目标 Sheet 复制到一个小的分析工作簿（但要保留依赖输入的实际数值）。

⑤ Excel 已经有公式，但绑定显示空白或不是数字

当前程序读的是 Excel 文件最后保存的缓存值，并不执行 Excel 公式。请先使用桌面 Excel 打开原文件、让它完成计算、保存，再重新导入为新项目检查。

⑥ 绑定 Excel 后为什么曲线没变化？

先确认已点击「应用绑定」、输入数据是有效数字、公式节点实际引用这个输入。若要使方案 B 与 A 不同，需要改变该参数的倍率或增量。

⑦ 右侧显示「无法计算：未知节点」

检查公式中是否拼错英文节点 ID，或删除了被其他公式引用的节点。变量名应与输入/公式节点 ID 完全一致。

⑧ 右侧显示循环依赖或除零错误

避免同一级公式互相引用形成环；累计结果请使用 prev_节点ID。除数可能为 0 时，要重新检查业务规则与公式输入。

⑨ 修改数值后没有立即更新

输入框使用 change 事件触发，输入完成后按 Tab 或点击其他位置。然后检查右侧是否出现计算错误提示。

⑩ 重新打开浏览器，项目不见了

确认是否使用同一个浏览器、相同本地地址及端口，并检查是否使用了无痕模式或清理过站点数据。

⑪ 怎么把导出的模型 JSON 再导回来？

目前 V1.6 网页界面没有导入模型 JSON 的功能。JSON 用于归档和开发核验；不要把它当作已经可以一键恢复的备份格式。

⑫ 导入新 Excel 后，原有项目被更新了吗？

没有。导入会创建新的项目记录，并为其附加一套默认的示例依赖模型。可以在左侧切换到旧项目。
