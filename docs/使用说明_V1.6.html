GAME BALANCE LAB · V1.6

数值依赖计算 · 使用手册

一个参数发生改变，如何沿着属性、战力、产出、养成成本的依赖路径自动计算？这份手册通过虚构 RPG 模型解释工作台的每一步。

完整离线 HTML 使用说明

01 · 运行程序

  1. 解压 Game_Balance_Lab_v1.6.zip。
  2. Windows 双击根目录 启动工作台.bat，或进入 dist 文件夹打开命令行执行：
py -m http.server 8000

浏览器打开 http://localhost:8000/。已在 dist 文件夹时不要重复加 --directory dist。

首页选择「先体验虚构 RPG 示例」，左侧出现输入参数与计算公式，右侧显示战力、经济指标和曲线。

03 · 导入你自己项目的 Excel

  1. 点击顶部「导入 Excel」，选择 .xlsx 或 .xlsm。
  2. 左侧「Excel 数据绑定」选择一个输入节点（例如基础攻击）。
  3. 选择数据所在的工作表 Sheet。
  4. 若同一单元格是固定参数，选「固定单元格」，输入 B2；若每级都有不同数值，选「按级读取列」，输入 C，起始行 3。
  5. 检查预览，点击「应用绑定」。
固定单元格例如设置「基础攻击」取 Sheet1!B2，全等级使用这个基准值。
按级读取列例如等级 1 使用 C3、等级 2 使用 C4，以此类推。

导入只是读取数值。请替换虚构 RPG 示例中的公式，以符合你项目实际的属性、战力和产消规则；否则推演结果只是示例规则下的假设。

04 · 建立你的公式依赖图

「计算公式」区域可以直接输入节点 ID 组成数学表达式。节点 ID 一律小写，例如：

attack = baseattack + (level - 1) * attackgrowth + weaponattack
power = round(attack * powerattackweight + defense * powerdefenseweight + hp * powerhpweight)
upgradecost = round(costbase * pow(costgrowth,level - 1) + attack * attacktraincost)
goldbalance = prev_goldbalance + goldincome - upgradecost

当来源参数更改时，系统根据显式引用自动计算下游公式。prev_goldbalance 代表上一级的累计余额；首次为 0。循环依赖或未知节点会在界面报错。

05 · 查看推演结果

指标卡与 A/B 曲线A：原基准输入按显式公式计算。B：参数经过倍率/增量调整，再依赖重算。
参数影响链可选定某个节点，观察它影响了哪些下游节点，及末级增减值。
逐级差异表比较不同等级下 A/B 的属性、战力、养成成本、关卡产出与累计余额。
导出CSV 包含逐级 A/B/差异；JSON 包含模型节点、表达式、输入映射，不附带 Excel 本体。

06 · 重要限制与常见问题

为什么修改 Excel 来源后某些属性没有变化？ 需要该输入节点被公式实际引用，才能形成真实依赖。没有引用关系的指标不会被擅自更改。

为什么读取不到 Excel 公式值？ 浏览器只读取 Excel 保存时写入的计算缓存值；未保存缓存结果时可能显示为空。请先用桌面 Excel 打开、重新计算并保存。

是否会完整重算上传的 Excel？ 不会。这里只计算你明确写入本工具的节点公式，不执行 VBA、外部链接或复杂跨表原生 Excel 公式。

是否需要联网？ 正常运行中无需服务器 API。浏览器通过本地 HTTP 服务加载程序，原始工作簿保存在本机浏览器存储中。
