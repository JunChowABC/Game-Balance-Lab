# Game Balance Lab V1.6 · 游戏数值依赖计算工作台

一个面向游戏策划的**本地、可复现的显式数值依赖引擎**：创建输入参数与公式节点，映射已有 Excel 的单元格或按级数值列，调整方案 B 的参数后，自动重算属性、战力、升级成本、关卡产出及累计经济指标。

> **隐私与开源说明**：仓库内只有程序源码、独立虚构的教学模型和说明，不包含任何真实商业项目 Excel / XLSM、宏、策划配置或真实数值结果。用户自行导入的工作簿只缓存在当前浏览器 IndexedDB。发布前请检查从个人浏览器导出的配置 JSON 是否含项目名/Sheet 名。

## 立即启动

Windows 用户可双击 `启动工作台.bat`；或进入 `dist/` 文件夹执行：

```bash
py -m http.server 8000
```

然后访问 `http://localhost:8000/`。

无需先导入 Excel：点击「先体验虚构 RPG 示例」即可运行独立示例。建议将「基础攻击」的**增量**改为 `100`，观察最终攻击 → 综合战力 → 金币产出 / 训练成本 → 累计金币盈余的联动。

## 一张页面里的工作流

1. **创建项目**：导入 `.xlsx/.xlsm` 或创建虚构演示模型。导入原表不会修改工作簿，也不会执行 VBA。
2. **建立依赖节点**：左侧「输入参数」可调整基准值、倍率、增量；「计算公式」允许新增、编辑和删除显式计算节点。
3. **绑定自己的 Excel**：选择待绑定输入节点、工作表、固定单元格（例如 B2）或按级数值列（例如 C 列，起始行 3）。可以扫描当前 Sheet 的有标签数值单元格作为建议。
4. **运行重算**：输入值变化时自动编译 DAG 和重算，错误将直接提示。未修改的指标复用基准结果。
5. **验证数值**：右侧查看 A/B 成长曲线、依赖影响链、战力/成本等指标以及逐级差异，可导出 CSV 或 JSON（JSON 不携带原始 Excel 文件）。

## 计算模型的定义与边界

- 示例是**虚构公式**，不是游戏行业的通用战力公式，也不等同于导入 Excel 内的任何未显式配置公式。可在工作台修改公式及创建新节点，以映射自己项目的游戏系统。
- 节点 ID 采用英文字母/数字/下划线，例如 `baseattack`、`power`、`upgradecost`。公式支持四则运算、幂、括号及 `round`、`max`、`min`、`abs`、`floor`、`ceil`、`pow`、`sqrt`、`log`、`exp`、`clamp`。
- 同一级公式通过依赖拓扑排序；跨级累计用 `prev_节点ID` 引用上一级结果（一级前初值为零）。循环依赖、未知变量、零分母以及缺失 Excel 缓存数值会报错。
- **A 基准**：取映射 Excel 的数字或输入默认值，通过显式节点公式计算。**B 方案**：仅对改动的输入应用 `A × 倍率 + 增量`；依赖图只重算受影响的分支，未受影响节点复用 A 的计算结果。
- Excel 映射支持固定单元格或逐级读取同一列。单个项目可绑定最多 12 张不同工作表，最多推演 500 级；加载单张 Sheet 的单元格上限及文件大小限制沿用 V1.5 解析器。
- **不支持**直接执行原 Excel 中任意复杂公式/跨表隐式依赖、运行 VBA、PowerQuery、外部链接或宏。对于尚未显式定义的系统，界面不会假装计算出准确结果。请在 Excel 中核实数据源和项目的实际公式。

## 安全与迁移

V1.6 沿用 V1.5 的浏览器本地项目存储。旧项目若没有依赖图，会附加一份**可编辑的虚构 RPG 演示模型**，用户需要自行绑定真实输入并替换示例公式。旧版单列曲线工具位于 `dist/legacy.html`，不再是首页；现有计算和项目缓存不会主动删除。

XLSM 中的 VBA 不执行，用户表格不会上传远程服务器；`dist/workbook-parser.js` 仅读取工作簿结构及缓存值。注意：此工作台在本地浏览器运行，第三方网站若被恶意注入同源脚本仍可能读取该域名下的缓存，因此不要与其他不可信本地应用混用相同地址和端口。
