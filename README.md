# Game Balance Lab V1.5

面向游戏策划的**本地 Excel 数值可视化推演工作台**。导入自己的数值工作簿，选择横轴和指标列，通过倍率、固定增量、复合增长或自定义公式创建假设方案，与原始数据进行曲线和逐行差异对比。

> **开源展示版说明**：仓库只包含应用源码、完全虚构的教学 Excel 和脱敏后的图文手册。**不包含任何真实项目工作簿、宏、商业模型、用户数据或个人文件路径。**

## 快速体验

1. 下载本仓库代码（Code → Download ZIP），解压。
2. Windows 安装 Python 后双击根目录 `启动工作台.bat`；或进入 `dist` 文件夹运行 `py -m http.server 8000`。
3. 使用 Chrome/Edge 打开 `http://localhost:8000/`。
4. 点击左侧「＋ 导入项目 Excel」，选择 `examples/示例角色成长.xlsx`。
5. 在工作表「角色成长」中选择横轴 **A 列（等级）**、纵轴 **D 列（攻击力）**、行范围 **4–53**。
6. 选择「整体数值倍率」，输入 **1.2**，观察基线与推演曲线差异。

完整步骤、标注截图与排错请打开 **[HTML 图文使用说明](docs/使用说明.html)**（下载后双击 HTML 可离线阅读）。

## 主要功能

- **原生 Excel 导入**：`.xlsx` / `.xlsm`，多 Sheet，原始数据只保存在当前浏览器的 IndexedDB。
- **指标映射**：选择 Sheet、横轴列、数值列、起止行，自动推荐可能的数值列。
- **假设推演**：整体倍率、逐级增量、复合成长率，以及受限数学表达式。
- **结果对比**：原值/调整值曲线、末项变化、异常候选、逐行差异和 CSV 导出。
- **项目管理**：本机多 Excel 项目切换、重命名、移除、参数自动保存、JSON 方案导出。
- **原表辅助预览**：可查看保存的单元格值和公式文本，用于核对来源。

## 模型边界

**本工具不是 Excel 完整计算引擎。** 推演使用 Excel *已保存的数值/公式缓存*，只对选中序列运行用户指定的假设规则；不会自动重算原工作簿的跨 Sheet 依赖、VLOOKUP、VBA、Power Query 或真实游戏战斗逻辑。`xlsm` 文件作为只读数据解析，不执行宏。

表格包含商业数据时请勿提交到公开 GitHub 仓库。使用本地服务器时请保持 `127.0.0.1/localhost`，不要把目录或服务暴露到公网。
